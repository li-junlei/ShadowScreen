# v0.16 GKME 转发验收

内置虚拟手柄已删除，仅保留外部事件转发。未操作手机。

1. 自行安装 build/ShadowScreen-v0.16.apk，启动 Shizuku trusted 副屏。
2. 将盖世游戏通过 Extend 投送到虚拟屏，主屏打开 GKME / 外接手柄转发页。
3. 在转发页上方显示 GKME 本机模式悬浮手柄，验证 ABXY、肩键、双摇杆和十字键。
4. 松手后确认停止移动；退出转发页、停止副屏或断开 Shizuku 后确认输入停止。
5. 主页面应只有转发入口，不再出现内置虚拟手柄或编辑器。

构建、签名和正式 APK 内容检查通过不替代手机游戏响应验收。
